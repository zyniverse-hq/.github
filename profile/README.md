## 📦 Open Source Projects

### [skills-registry](https://github.com/zyniverse-hq/skills-registry) — Claude Skills Registry

A public registry of production-grade Claude skills built by the Zysk engineering team.

Install any skill into Claude Code, Cursor, or any compatible AI agent:

```bash
# Install all Zyniverse skills
npx skills add zyniverse-hq/skills-registry -a claude-code -y

# Install a specific skill
npx skills add zyniverse-hq/skills-registry --skill deploy-shield -a claude-code
```

Browse the registry → **[zyniverse-hq.github.io/skills-registry/website](https://zyniverse-hq.github.io/skills-registry/website)**

Skills cover: QA & test automation · Pre-deploy safety · Business & sales automation · Engineering practice · Frontend & integration · Infra & security · Document generation · AI agents & MCP servers

## 🤝 Contributing

The **skills-registry** is open for contributions from anyone.

The workflow: **fork → create branch `skill/<your-skill-name>` → add your `SKILL.md` → open a PR.** CI validates every submission automatically.

Read the full guide → [CONTRIBUTING.md](https://github.com/zyniverse-hq/.github/blob/main/CONTRIBUTING.md)
